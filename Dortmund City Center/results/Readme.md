## Results

### 3D Reconstruction of Street Light Poles

This folder contains the 3D reconstruction results of street light poles for the test image of Dortmund City Center.

The reconstructed results are provided in PLY format.

**Coordinate Reference System (CRS):**
- EPSG:25832 – ETRS89 / UTM zone 32N
- Coordinate units: meters

  The PLY file contains georeferenced 3D reconstruction results in the projected coordinate system specified above.
